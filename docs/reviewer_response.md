# Draft response to the independent review

This is a working author response to the supplied independent review. It is
not an editor decision. The manuscript and evidence bundle were revised locally
and rerun after each implementation change.

## Overall positioning

We agree that the release is a reference implementation and validation
prototype, rather than a detector-hardware certification or a claim of live
trigger performance. The abstract, validation protocol, discussion, and
conclusion now state that the guarantee is conditional on the declared sampling
model and that the public LHCO result is an acceptance-probability result.

## Major points

1. **Narrow experimental scope.** We added `examples/assumption_boundary_stress.py`
   and the `assumption_boundary` figure. At 50,000 repeats, the stationary
   Poisson reference covers 0.99108, while intentionally misspecified two-state
   burst and gamma-mixed windows cover 0.19386 and 0.56002. These rows are
   explicitly negative boundary diagnostics and are excluded from the 36-cell
   certified sweep. The paper now describes the release as a conditional
   reference implementation and lists time dependence, correlation, weighted
   Monte Carlo, dead time, and live-time integration as future adapters.

2. **Independence evidence.** The LHCO adapter now records the split rule,
   calibration/deployment event-ID hashes, and an `event_id_disjoint` check that
   fails on a non-empty intersection. The certificate records that statistical
   independence remains a caller/data assumption; distinct block IDs are not
   treated as proof. This is also stated in the limitations section.

3. **Threshold selector/code alignment.** The public path now calls
   `choose_acceptance_threshold(..., selection_alpha=alpha_cell)` and records
   `clopper_pearson_upper_bound` in every public cell. The explicit-rate sweep
   records `fixed_binary_threshold_code_1` and does not perform adaptive
   selection. The generic `choose_threshold` helper remains an empirical-tail
   selector for callers with an explicit exposure target. The distinction and
   alpha allocation are described in Sec. 2.3 and checked in
   `tests/test_acceptance.py`.

4. **Rate-register margin.** The manuscript now defines the margin as a
   deterministic representation bound, separate from statistical uncertainty,
   and distinguishes nearest-even (`Delta_r/2`) from floor/truncation
   (`Delta_r`). It states which quantity enters the pass predicate and gives a
   numerical example: point estimate 7.9 Hz, Poisson upper bound 9.4897902928
   Hz, 0.05 Hz nearest-even register margin 0.025 Hz, and 12 Hz budget.

5. **Monte-Carlo coverage interpretation.** Captions and text now label all
   coverage numbers as implementation diagnostics with repeat-level intervals;
   the exact Clopper--Pearson and Poisson statements remain the formal claims.

6. **Cell-level replay.** `reports/reviewer_replay_table.csv` contains all 63
   public and explicit cells with parameters, counts, bounds, margins, counter
   limits, status, and refusal reasons. It is regenerated by
   `examples/make_replay_table.py` from `reports/unified_benchmark.json`.

7. **Environment pinning.** `requirements-lock.txt` records the versions used
   for the checked-in replay: NumPy 1.26.4, SciPy 1.15.3, pandas 2.1.3,
   PyTables 3.10.1, Matplotlib 3.10.9, and pytest 8.4.2.

## Minor points addressed

- The abstract now says “score-width, deployment-prefix, and acceptance-target
  cells”.
- Reproducibility commands use copyable PowerShell backticks.
- Complexity is described as sorting-based worst-case `O(n log n)` with `O(u)`
  additional storage.
- The paper states that the public unsigned-format fractional-bit count equals
  the total width used in the sweep.
- The refusal-plot caption gives an explicit overlap interpretation.
- The comparison with YODA and general HEP utilities is framed as an interface
  distinction rather than a superiority claim.
- Figure 1 vertical-edge labels were moved beside the arrow shafts and given an
  opaque background to prevent text/arrow overlap.
- `LICENSE` and `CITATION.cff` were added.
